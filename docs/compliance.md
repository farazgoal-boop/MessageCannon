### Your Responsibility

1. **Never Share Credentials**
   - Don't give QR code to others

2. **Monitor Activity**

3. **Respect Rate Limits**

## Account Suspension Risk

WhatsApp may suspend your account if:

- Sending spam/unsolicited messages
- Violating 3+ complaints
- Repeatedly exceeding rate limits
- Using automated scripts without authorization
- Impersonation or fraudulent claims
- Harassment or threatening content

## If Your Account Gets Blocked

**Immediate Actions:**
1. Stop using MessageCannon with that number
2. Wait 24-72 hours for automatic unblock
3. Contact WhatsApp Support if not unblocked

**Long-term Solutions:**
1. Review what caused block
2. Adjust sending practices
3. Use more conservative settings
4. Ensure proper consent documentation

**Permanent Ban Recovery:**
- Not possible with same number
- May need to use different phone number
- Change business practices

## Using Safely

### Best Practices

1. **Start Small**
   - Test with 5-10 contacts first
   - Monitor for any warnings
   - Scale gradually if all OK

2. **Use Conservative Settings**
   - 45+ second delay
   - Enable jitter
   - Max 30-40 messages per session
   - Multiple sessions per day OK

3. **Segment Audiences**
   - Separate VIP from regular
   - Different message for each group
   - Track responses carefully

4. **Document Everything**
   - Keep consent proof
   - Archive all messages
   - Track unsubscribe requests
   - Log complaints

5. **Clean Data**
   - Remove invalid numbers
   - Update contact information
   - Remove opt-out requests immediately
