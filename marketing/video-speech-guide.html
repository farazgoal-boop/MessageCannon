About The App And Backend

If you want to mention the technical side in your speech or on the presentation page, use this short summary.

  • MessageCannon is a Python desktop application built for Windows with a CustomTkinter interface.
  • The backend handles contacts, message templates, delivery reporting, scheduling, backups, and exports through structured Python modules.
  • It uses SQLite for local data storage, so contacts, logs, reports, and app state stay organized on the machine.
  • WhatsApp session handling and message automation are managed in the Python core layer, with persistent session support for smoother reuse.
  • The project also includes licensing logic, validation utilities, reporting tools, and packaging support for EXE and installer builds.
