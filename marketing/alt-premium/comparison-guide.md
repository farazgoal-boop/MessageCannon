# Style Comparison Guide

## Main Set
The main `marketing` folder uses a louder, energetic, colorful product identity.

## Alternate Premium Set
The `alt-premium` folder uses a more corporate, luxury, high-trust visual style.

## When to Use Which
- Use the main set for social attention and bold product marketing.
- Use the alternate premium set for Fiverr, Upwork, LinkedIn, proposals, and client-facing presentations where trust and polish matter more.
