## 🚀 Quick Start

### Installation
1. Download `MessageCannon_Setup.exe`
2. Run installer
3. Launch from desktop

### First Campaign
1. Click **Import Contacts** → Upload Excel/CSV
2. Compose message using {name}, {amount} etc.
3. Click **Preview** → Verify all messages
4. Click **Start Send** → Watch QR code appear
5. Scan with WhatsApp Web → Sending begins

### Safety Features (Built-in)
- ✅ Minimum 30 seconds delay between messages
- ✅ Maximum 50 messages per session
- ✅ Random jitter to avoid pattern detection
- ✅ Requires recipient consent confirmation

## 📋 System Requirements
- Windows 10 or 11
- Python not required (standalone EXE available)
- Active WhatsApp account
- Internet connection for sending

## 🛠️ Build from Source

```bash
git clone https://github.com/farazgoal/MessageCannon.git
cd MessageCannon
pip install -r requirements.txt
python src/main.py
```

## 🔧 Build Standalone EXE

```bash
pip install -r requirements-dev.txt
build.bat
```

For a portable package:

```bash
portable_build.bat
```
