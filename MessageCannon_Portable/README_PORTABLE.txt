MessageCannon Premium Portable Edition
=====================================

This package contains the premium portable workspace for MessageCannon.
Run MessageCannon.exe directly. No separate installation is required.
All local app data, portable markers, and bundled assets stay with this folder.

Included in this portable package:
- Premium messaging workspace UI
- Persistent session support
- Delivery analytics and reporting tools
- Built-in activation-ready licensing flow

First launch:
- Open MessageCannon.exe
- The app starts with branded premium startup screens
- If the 3-day trial is active, continue directly into the workspace
- If the trial has expired, activate from the startup gate or Settings

System requirements:
- Windows 10/11
- Active WhatsApp account
- Internet connection for WhatsApp Web usage

Notes:
- Keep your paid activation passkey private
- Moving this folder keeps the portable bundle intact
- Deactivation does not reset the free trial
